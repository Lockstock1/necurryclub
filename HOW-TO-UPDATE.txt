=====================================================
HOW TO UPDATE THE NORTH ESSEX CURRY CLUB WEBSITE
=====================================================

Live site: https://lockstock1.github.io/necurryclub/
Short link: https://bit.ly/necurryclub
Repo:       https://github.com/Lockstock1/necurryclub

-----------------------------------------------------
OPTION A: EDIT DATA.JS DIRECTLY
-----------------------------------------------------
1. Open data.js in a text editor (e.g. VS Code, Notepad++)
2. Find the entry you want to change (search by id or restaurant name)
3. Edit the fields (name, location, pub, rating, comment, etc.)
4. Save the file
5. Push to GitHub (see PUSHING CHANGES below)

To ADD a new entry:
- Copy an existing entry block at the end of the array (before the closing ];)
- Change the id to the next number
- Fill in the details
- Optional: add coords: [lat, lng] to pinpoint the restaurant on the map.
  Look up the postcode at https://api.postcodes.io/postcodes/<POSTCODE>
  (returns latitude & longitude). Without coords, the marker falls back to
  the town-level coordinates in app.js (locationCoords).
- Save and push

To DELETE an entry:
- Remove the entire { ... }, block for that entry
- Save and push

-----------------------------------------------------
OPTION B: EDIT VIA THE WEBSITE UI (RECOMMENDED)
-----------------------------------------------------
1. Open your local site: http://localhost:8080
   (start the server: python -m http.server 8080)
2. Go to Edit Entries, unlock with password: curryclub2021!
3. For a NEW entry:
   a. Drop the photo into the images/ folder first
   b. Click "➕ Add New Curry Night"
   c. Fill in the form. Image Filename = just the file name
      you dropped in images/ (e.g. ifraaz_witham.jpg)
   d. Optional: enter the restaurant's postcode — the site
      looks up the lat/lng automatically and pinpoints it on the map
   e. Submit
4. For edits to existing entries: click cells directly, or use the
   row actions to remove photos / change attendees, etc.
5. When you're done, click "⬇ Download Updated data.js"
6. Save the downloaded file over the project's data.js
   (default download location, then move it to the project folder)
7. When prompted, click OK to clear local edits (recommended —
   otherwise they linger and can create duplicates next time)
8. Push to GitHub (see below)

The old console-based flow is still there if you need it:
Open F12 > Console, type exportCurryEdits(), copy the JSON.

-----------------------------------------------------
PUSHING CHANGES TO GITHUB
-----------------------------------------------------
Open a terminal in the project folder and run:

    git add -A
    git commit -m "Updated curry nights"
    git push

If git is not found, run this first:
    set PATH=%PATH%;C:\Program Files\Git\cmd

The live site updates automatically within 1-2 minutes.

-----------------------------------------------------
CHANGING THE EDIT PASSWORD
-----------------------------------------------------
1. Open browser console and run (replace yournewpassword):
   crypto.subtle.digest('SHA-256', new TextEncoder().encode('yournewpassword')).then(b => console.log([...new Uint8Array(b)].map(x=>x.toString(16).padStart(2,'0')).join('')))
2. Copy the hex string it prints
3. Open app.js, find EDIT_PASSWORD_HASH and replace the value
4. Save and push

Current password: curryclub2021!

-----------------------------------------------------
BUMPING THE CACHE VERSION (if changes don't show)
-----------------------------------------------------
In index.html, find all ?v=17 references and change to ?v=18
(or whatever the next number is). This forces browsers to
reload the latest files.

-----------------------------------------------------
STARTING THE LOCAL SERVER FOR TESTING
-----------------------------------------------------
Open a terminal in the project folder and run:
    python -m http.server 8080

Then visit: http://localhost:8080
